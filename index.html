Mol* Volume Tools

Interactive tools for cryo-EM maps, built on Mol*. Open a local .mrc/.map file inside each tool.

Volume Segmentor

Split a map into bodies by drawing polygons from several views, keep the remainder as its own body, remove dust, preview soft masks and export one MRC mask per body (extend + cosine soft edge).

Volume Mask Creator

Draw polygons to carve a single soft-edged mask from a map (or around an atomic model) and export it as MRC.
Source: github.com/Poko18/molstar
